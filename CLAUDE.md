# SonicLight

Before working on this project, read:

1. `docs/requirements.md`
2. `docs/architecture.md`
3. `docs/decisions.md`

These documents contain the project context and intentional decisions.

## Project structure

- `client/` — React frontend
- `server/` — Node + PostgreSQL backend

## Working rules

- Do not implement features outside the requirements unless explicitly asked.
- Prefer simple, maintainable solutions appropriate for a technical test.
- Do not over-engineer the application.
- Before changing an existing pattern, inspect the surrounding code and follow the existing conventions.
- Keep frontend and backend responsibilities clear.
- Avoid adding dependencies unless they solve a real requirement.
- After implementing a task, run the relevant tests, linting, type checking, and build commands available in the project.

When requirements are ambiguous, prefer the simplest interpretation that is consistent with the docs and existing code.
